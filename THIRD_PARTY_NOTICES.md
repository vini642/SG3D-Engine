# Upstream provenance and acknowledgments

SG3D Studio evolved from extracting and adapting rendering code from:

- **Tobias Friedly (Game of Tobi)** — [smg-gba](https://github.com/TobiasFriedly/smg-gba), the original Super Mario Galaxy GBA project.
- **Joshua Barretto (zesterer)** — [GitHub profile](https://github.com/zesterer), credited by `smg-gba` as the base engine author.
- The upstream README also mentions code from [SMGCommunity / Petari](https://github.com/SMGCommunity/Petari).

The current SG3D runtime includes substantial modifications, editor integration and new game-engine facilities; **authorship/provenance by file and block has not yet been fully audited**. This acknowledgment is not proof of redistribution rights. See `LICENSE_STATUS.md`.

No commercial Mario or Pokémon model, sound, texture, or ROM assets are bundled with this repository.
